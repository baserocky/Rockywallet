# i18n otomatis + RTL

## Performa MutationObserver

- Hanya `childList` (tanpa `attributes` / `characterData`)
- Debounce **120ms** + `requestAnimationFrame`
- Batch root nodes (merge overlapping subtrees)
- `disconnect` saat `applyDom` massal, `observe` lagi setelah selesai
- Abaikan `SCRIPT` / `STYLE` / `LINK` / SVG

## RTL

```js
I18N.setDir('rtl');   // force RTL
I18N.setDir('ltr');   // force LTR
I18N.setDir('auto');  // default — RTL jika bahasa ar/he/fa/ur
I18N.getDir();        // 'rtl' | 'ltr'
```

Disimpan di `localStorage.br_dir`.  
`html[dir=rtl]` + class `.rtl` mengaktifkan CSS mirror (flex reverse, chevron flip, angka tetap LTR).

## Bahasa

```js
I18N.setLang('en' | 'id');
I18N.t('preferences');
I18N.apply();
```
